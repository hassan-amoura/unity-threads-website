# Product images

Place **product photos** here. Each product’s image path is set in `lib/data/products.ts`.

- Use the product **slug** as the filename (e.g. `hopeful-horizon-tee.jpg`, `soft-spectrum-tee.jpg`) so the path is `/images/products/hopeful-horizon-tee.jpg`.
- In `lib/data/products.ts`, each product has an `images` array. Set `src` to `/images/products/yourfilename.jpg` (or the shared `placeholder.svg` until you have real photos).
- Recommended size: around 800×1000 px (portrait) per product.
