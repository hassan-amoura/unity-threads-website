# About page images

Place the **founder/owner photo** here (shown on the About page).

- **Recommended:** `founder.jpg` or `founder.webp` (portrait works well, e.g. 600×720).
- After adding your file, set `siteContent.about.founderImagePath` in `data/siteContent.ts` to `/images/about/yourfilename.ext` if you use a different name.
