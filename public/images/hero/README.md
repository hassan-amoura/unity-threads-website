# Hero images

Place the **homepage hero image** here (the large image above the “Wear the message” headline).

- **Recommended:** `hero.jpg` or `hero.webp` (landscape, e.g. 1200×600 or 1600×800).
- After adding your file, set `siteContent.homepage.heroImagePath` in `data/siteContent.ts` to `/images/hero/yourfilename.ext` if you use a different name.
